# CRYS(tal cutting)

crys is a gem cutting extension for prism! With crys, you can enter in cuts and generate a stone design from a diagram, or design your own! Since it generates it in prism, you can use prism's full rendering capabilities to emulate whatever material you'd like to see how the cut would look on it!

To include crys in prism, add this repo as a tinymodule in the prism `.tinyconf`, and cleanbuild it from there! By default, crys appends itself to the last defined trailing panel in prism's ui config.
